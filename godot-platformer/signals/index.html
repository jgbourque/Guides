How game objects communicate in Godot

In this guide, you'll build a collectible coin in Godot. Making it is a small project on its own — but it's also a first look at how game objects can notice each other and react. In Godot, that kind of communication happens through a signal.

This is one of the simplest uses of signals. There's a lot more you can do with them, but building the coin gives you enough of the shape to start exploring on your own.

    Quick rebuild checklist

    1. Create Coin as an Area2D.
    2. Add Sprite2D for the coin image.
    3. Add CollisionShape2D for the coin hitbox boundary.
    4. Attach coin.gd to the Coin Area2D.
    5. Use the final script below.
    6. Create or open a test level.
    7. Add the existing Player scene.
    8. Paint or place a simple floor with collision.
    9. Add one or more Coin instances to the level.
    10. Run the game and move the player into the coin.

    Final coin script

    When you recreate this in Godot, attach this script to the Coin Area2D node. If your template creates extra unused lines, your final coin script can be this simple.

    # coin.gd
extends Area2D

func _ready():
    body_entered.connect(_on_body_entered)

    queue_free()
